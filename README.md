## 📖 About the Project

**GAMEVERSE** is a fully interactive single-page gaming showcase website designed to feel like a premium AAA game promotional site. It combines cinematic imagery, a live Three.js particle system, GSAP scroll animations, dynamic theme switching, and a responsive layout across all devices.

The project focuses on **visual quality**, **smooth performance**, and **real interactivity** — every button, filter, theme, modal, and search feature actually works.

---

## ✨ Live Features

### 🎬 Cinematic Hero Section
- Full-screen hero with parallax background
- GSAP text reveal and stagger animations
- Dynamic game switcher (Ghost of Tsushima / The Last of Us / Red Dead Redemption 2)
- Mouse-movement parallax effect
- Animated scroll indicator

### 🌌 Three.js 3D Background
- Real WebGL particle system
- Fog, soft lighting, and mouse interaction
- Responsive resizing on window change
- Auto-reduces particle count on mobile devices
- Respects `prefers-reduced-motion`

### 🎴 Interactive Game Cards
- 3D tilt on hover
- Image zoom effects
- Gradient overlays with glow
- Click to switch the active game
- Staggered reveal on scroll

### 🎨 Multiple Themes
- **Samurai** — Black / Crimson / Cream
- **Apocalypse** — Dark Green / Black / Brown
- **Western** — Brown / Gold / Black
- **Neon** — Cyan / Purple / Black
- Theme selection persists via `localStorage`

### 🖼️ Cinematic Gallery
- Filter by game
- Masonry layout
- Full lightbox with previous/next controls
- Keyboard navigation (Arrow keys + Escape)
- Close button and backdrop click

### 🔍 Live Search
- Search games, characters, genres, and features
- Live results as you type
- Escape key to close
- Click a result to jump to that game

### 🎞️ Trailer Modal
- Fullscreen YouTube trailer embeds
- Escape key and backdrop click to close
- No autoplay with sound

### 📊 Animated Statistics
- Counters animate when scrolled into view
- 95+ Hours · 3 Worlds · 10+ Characters · ∞ Stories

### 📱 Fully Responsive
- Optimized for 1920px, 1440px, 1024px, 768px, 430px, and 390px viewports
- Hamburger menu on mobile devices
- Custom cursor disabled on touch devices

### ♿ Accessibility
- Semantic HTML5 markup
- ARIA labels on all interactive elements
- Keyboard navigation support
- Visible focus states
- Screen-reader friendly modals
- `prefers-reduced-motion` support

## 🚀 Getting Started

### Prerequisites

Ensure you have the following installed:

- **Node.js** (v18 or higher) — [Download here](https://nodejs.org)
- **npm** (bundled with Node.js)

Verify your installation:

```bash
node -v
npm -v
Installation
Clone the repository:

bash
git clone https://github.com/your-username/gameverse.git
cd gameverse
Install dependencies:

bash
npm install
⚠️ If the esbuild install script is blocked, run:

bash
npm install --foreground-scripts
▶️ Running Locally
Start the development server:

bash
npm run dev
You should see output similar to:

text
VITE v5.4.21  ready in 435 ms

➜  Local:   http://localhost:5173/
➜  Network: use --host to expose
Open http://localhost:5173 in your browser.

The page auto-reloads whenever you save changes to any file.

Stop the Server
Press Ctrl + C in the terminal.

🏗️ Build for Production
Create an optimized production build:

bash
npm run build
This generates a dist/ folder with minified assets.

Preview the production build locally:

bash
npm run preview
🌐 Deployment
Deploy to Netlify
Push your project to GitHub

Go to netlify.com → Add new site → Import from Git

Configure:

Build command: npm run build

Publish directory: dist

Click Deploy

Deploy to Vercel
Push your project to GitHub

Go to vercel.com → New Project → Import repository

Vercel auto-detects Vite. Click Deploy

Deploy to GitHub Pages
Install the gh-pages package:

bash
npm install -D gh-pages
Add these lines to package.json:

json
"homepage": "https://your-username.github.io/gameverse",
"scripts": {
  "deploy": "npm run build && gh-pages -d dist"
}
Deploy:

bash
npm run deploy
🎨 Themes
GAMEVERSE ships with four built-in themes. Switch via the palette icon in the navbar. Your choice is saved automatically in localStorage.

Theme	Colors	Inspired By
Samurai	Black / Crimson Red / Cream	Ghost of Tsushima

Western	Brown / Gold / Black	Red Dead Redemption 2

Each theme changes:

Background and surface colors

Accent and highlight colors

Button and card styling

Glow effects

Three.js particle color

Problem	Solution

White or blank page	Remove @import "tailwindcss"; from style.css if present
Failed to load /main.js	Ensure main.js exists in root and index.html references ./main.js
esbuild install script blocked	Run npm install --foreground-scripts
Loader stuck at 0%	Open browser console (F12) and check for errors
Port 5173 already in use	Run npm run dev -- --port 5174
Images not loading	Check internet connection; remote images require network access
